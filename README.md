# E-commerce Sales & Customer Analytics

## Project Overview
This Power BI project analyzes e-commerce sales and customer data to identify sales trends, customer behavior, and regional performance.

## Objectives
- Analyze sales performance by category and region
- Understand customer distribution and purchasing behavior
- Identify top-performing customers and states
- Support data-driven business decisions

## Tools & Skills
- Power BI
- DAX
- Data Visualization
- Business Intelligence
- Sales and Customer Analytics

## Dashboard
The dashboard includes an Executive Overview and Customer Analytics.
